# Result Management System

A modern, comprehensive web application for tracking earnings, performance, and result history. Built with performance and user experience in mind, featuring a premium design and Progressive Web App (PWA) capabilities.

![App Logo](public/logo.png)

## 🌟 Features

- **Dashboard Overview**: Visual analytics of earnings and performance metrics.
- **Interactive Charts**: Dynamic charts powered by `recharts` for data visualization.
- **Data Management**: Easy import and handling of result data (CSV/Excel/Google Sheets support).
- **Responsive Design**: Fully responsive layout optimized for mobile, tablet, and desktop.
- **PWA Support**: Installable as a native-like app on supported devices with offline capabilities.
- **Modern UI**: Polished interface using Tailwind CSS with glassmorphism and smooth transitions.
- **Export Capabilities**: Ability to export charts and reports as images.

## 🛠️ Tech Stack

- **Frontend Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Charts**: [Recharts](https://recharts.org/)
- **PWA**: [Vite Plugin PWA](https://vite-pwa-org.netlify.app/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Data Parsing**: [PapaParse](https://www.papaparse.com/)

## 🚀 Getting Started

Follow these instructions to get the project up and running on your local machine.

### Prerequisites

- Node.js (v18 or higher recommended)
- npm (comes with Node.js)

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   cd result-web
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`.

## 📦 Building for Production

To create a production-ready build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 📱 Installing as PWA

This application is a Progressive Web App. You can install it on your device:

- **Desktop**: Look for the install icon in the address bar (Chrome/Edge).
- **Mobile (iOS)**: Tap "Share" -> "Add to Home Screen".
- **Mobile (Android)**: Tap the menu dots -> "Install App".
